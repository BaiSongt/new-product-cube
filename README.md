# 大型落地镗铣床数字化加工单元 · Three.js M6

本版基于 M5 独立升级，**车体外壳按 X/Y/Z 三方向同步放大 10%**，保持原装夹台与机床场景；新增固定 90°角度头的**人工换装示意**以及顶部局部特征沿 −Y 方向的加工动作。原 M5 工程未覆盖。

## Windows 本地运行

```powershell
npm install
npm test
npm run build
npm run dev
```

访问终端打印的本地网址，点击底部 **「换头」「角铣」** 阶段快捷键或直接播放；也可用左侧「90°角度头」视角观察。推荐 1920×1080 屏幕。

## 模型及坐标

- 工件模型生成入口：`src/models/workpiece.js`；实际放大系数：`src/core/geometry.js` 的 `HULL_SCALE`。侧孔、轮孔、顶部炮塔真实敞口及过程标记同步缩放。
- 直镗杆机床运动顺序：`X 立柱 → Y 主轴箱 → Z 滑枕 → 主轴接口 → 刀柄 → 镗杆`。标准刀具从 +Z 朝侧壁定位，与 A/B 孔共轴。
- 角度头：输入轴 **+Z**，输出轴 **−Y**；壳体安装于主轴附件接口，模拟防转销/止转块，输出刀具独立旋转。TCP 由 `src/core/angle-head.js` 定义，**不继承直镗杆刀尖坐标**。
- 顶部加工点选在右侧顶板外缘，**避开炮塔环开口**。向下刀具仅接近顶板，保持 ≥90 mm 的示意净距；不会在运行时切削或修改网格。
- 角度头示意伸出行程 2.8 m 是本虚拟场景的动画假设，**不代表任何实机具有该行程或实际无碰撞**。现实中必须先核实 X/Y/Z/W 行程、角度头外形包络、接口规格、承载、止转销位置、机床/夹具/工件干涉。
- 工作间继续与研发办公网物理隔离；DNC 为受控传输，不包含远程循环启动。

## 九阶段时间轴（150 秒，演示时间压缩）

研发工艺 → 装夹就位 → 机床找正 → 离线交接 → 直镗杆粗/精镗（A/B） → **回换头位、停转退刀、更换角度头** → **顶板 −Y 方向进给/退刀** → 卸附件/换测头与测量规划 → 质量追溯。

## 验收边界

`npm test` 包括主轴同轴、90°角度头独立 TCP、附件互斥、停转换头、Y 向安全净距、横移前退刀、顶板孔位不与炮塔开口重叠、同源模拟 JSON 记录等测试。**测试不等价于实机碰撞仿真，也不包含实机参数标定、NC 后置或正式测量。**
