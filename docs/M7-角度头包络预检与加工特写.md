## 技术边界

这是部分对象、部分时间点、简化包络的保守预检，不能覆盖夹具、其他机床部件、切削动力学、实际附件止转方式、真实行程、NC 可达性，也不代表整机碰撞认证。自动化测试的 clear 仅表示当前虚拟几何关系符合预设阈值。

## 本地验收

Windows 下执行 npm install、npm test、npm run build、npm run dev。进入“换头”和“角铣”，打开“角度头包络”，确认线框与工具同动；切换“顶部加工特写”，观察角度头 -Y 方向接近和撤离。展开过程 JSON 并确认所有认证字段为 false。检查炮塔顶部敞口不被几何挡住。

原 M6 的 45 项测试保留；新增 8 项几何、反向故障与 UI 数据回归。当前工作环境未安装 Vite，尚未完成生产构建或实际 WebGL 视觉验收。
