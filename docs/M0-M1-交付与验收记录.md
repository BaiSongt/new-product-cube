# M0+M1 三维交互原型交付与验收记录

**日期：** 2026-10-15  
**版本：** v0.1.0 / M0+M1  
**范围：** 单台大型落地镗铣床数字化加工单元（Three.js）

## 已完成

1. 一个 WebGL 渲染上下文与一个主 `Scene`；室内地坪、钢结构、地轨、吊装空间、CNC 操作站和机旁工作间。
2. 移动立柱 X、主轴箱 Y、滑枕 Z 的可分离示意运动；刀柄/镗杆/刀尖从属于滑枕层级。
3. 前方侧面安装孔与左右端面的车轮轴孔分离建模；**后者理论轴线共线并沿 X**。
4. 五视角、信息浮层、三维拾取、轴线显示开关、示意运动时间轴、暂停、复位和变速播放。
5. 工作间 DNC/MDC 屏幕、机床与工作间的本地有线示意；不包含办公网络/互联网桥接或远程 CNC 启停。
6. Vite + Three.js 源码、场景数据合同、Windows 启动脚本、单元测试与说明书。

## 本地 GLM/LOCAL_VERIFIER 建议验收步骤

1. 在 Windows 研发电脑执行 `npm install && npm run test && npm run build`，记录 exact HEAD 或压缩包 SHA-256。
2. `npm run dev`，用 Chrome/Edge 打开本地页面。核对场景启动、透视/缩放、帧率及控制台无报错。
3. 检查单台镗铣床、工作间、厂房和大型工件均可见，视角切换无地坪穿透。
4. 播放/暂停/拖动/变速 100 次，无机床与工件坐标漂移；前方安装孔定位对应两个固定中心，刀柄与镗杆随滑枕移动。
5. 选中移动立柱、主轴箱、滑枕、刀具、夹具、工件、左右端面车轮轴孔、CNC 和工作间，检查面板说明。
6. 验证左右车轮轴孔位于工件两端，沿 X 同轴，且前方安装孔的动画不冒充端面轴孔加工。
7. 执行 `npm run build` 后将 `dist/` 转入断网电脑，通过静态 HTTP 服务访问，检查无外网资源请求。
8. 记录浏览器、GPU、FPS、现场截图与 PASS/FAIL 结果；FAIL 在同一工程修复，不进入 M2。
