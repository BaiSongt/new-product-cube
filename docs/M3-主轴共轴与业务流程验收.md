# M3 主轴—目标孔共轴与业务流程深化验收

**日期：2026-10-15**  
**工程目录：** `boring-mill-threejs-m3`  
**基线：** M2 参数化车体工艺联动  
**属性：** 建设方案交互演示，非真实机床数字孪生、非 NC 仿真及非质量检测系统。

## 1. 本轮最重要的修复

M2 让机床 X 向位置加上 `0.24 m` 的“刀尖局部偏置”对准孔位，尽管某个点的位置吻合，画面中可见主轴、镗杆和刀具却不在孔的共同轴线上。

M3 取消该偏置，以 `src/core/geometry.js` 为共享坐标契约：

- 主轴轴向：局部 `+Z`；轴心 `X=0`、`Y=0.02 m`。
- 机床安装原点：世界 `Z=-6.4 m`。
- 车体原点：世界 `(0,1.11,2.80) m`；近侧侧壁外表面约世界 `Z=0.71 m`。
- 上部两侧装孔示意中心：`(-2.42,2.75,0.71)` 和 `(2.59,2.75,0.71)`，孔轴均为 `+Z`。
- 定位公式：`machineX = hole.x - spindleLocalX`、`headY = hole.y - spindleLocalY`。镗杆实体中心线与此轴向一致，镗刀片仅保持径向小偏移。
- 主轴运动方向与目标孔理论轴线平行。进给段内垂直轴线距离为 `0`（数学模拟），不含设备误差；最大示意伸刀终点和近侧壁保持 `0.06 m` 安全距离。

**特别区分**：屏幕上的 `0.0 mm（模拟）` 是程序推导得到的理论几何偏差，**不是**机床定位精度、同轴度实测结果或质量保证承诺。

## 2. 仍保留的车体几何

- 自建 Three.js 参数化车体壳体、前后倾斜板与侧板。
- 炮塔安装位置为真实敞开的顶部圆口，下面是凹下的内底板，不能盖上顶板。
- 两侧各 5 处车轮轴孔，每侧 2 处安装孔，采用 `Shape.holes + ExtrudeGeometry` 实网格开孔。
- 无炮塔、火炮、履带、车轮等整车附属件；不导入旧版黑色 GLB。

## 3. 新增工程演示

### 3.1 机床与刀轴

在找正及孔系加工阶段，在三维机床上显示与可见镗杆重合的青色轴线。近侧目标孔的轴线与镗杆共线；切换两孔期间，底部状态栏显示非零对中偏差，到位后归零。定位基于实际三维关节链的世界坐标计算，同时与纯数学几何值交叉核验。

### 3.2 DNC / MDC 工作间

保留研发与生产两个安全域，只有**受控光盘或 U 盘的人工移交**，没有研发区到生产区的网络连接。工作间到机床的本地传输仍为彩色流动光点说明动画。业务看板增加：DNC 程序清单、审批与版本核对；MDC 只读的虚拟状态、主轴和程序执行说明，**没有实际 CNC 接口**、不提供远程启停。

### 3.3 在机检测与质量追溯

两侧轮孔的同轴设计基准高亮，在每个孔的两处**侧板壁厚内**截面显示演示采样点。该规划仅用于讲解测头多截面测量概念；真实孔径、有效测量深度、点位数量、拟合方法及测量不确定度必须经客户计量部门与现场实际测头核验。薄壁上的两截面距离很短，**不能据此证明真正的空间轴线测量有效性**。正式终检仍需独立测量。

模拟过程记录可导出 JSON，记录阶段、纯数学目标孔偏差、模拟轴向间隙与 `simulated:true`/`measured:false`；不伪造 NC 散列值或质量合格结论。

## 4. 代码和自动验收

- `src/core/geometry.js`：唯一共享几何和孔轴计算契约。
- `src/core/trajectory.js`：确定性 X/Y/Z、装夹、时间轴和示意进给路径。
- `src/models/machine.js`：共轴的主轴/镗杆/刀头及可见中心线。
- `src/models/workpiece.js`：实体视觉开孔及虚拟检测采点图层。
- `src/core/process-demo.js`：离线受控交接、MDC、检测与归档模拟状态和报告。
- `src/main.js`：镜头、阶段导航、业务看板、实时三维轴线偏差与 JSON 导出。

自动化执行 `npm test`，语法执行 `node --check`。包括全过程 400 多个进给/退刀采样点检查理论轴线重合及刀尖到近壁的距离；不是碰撞求解器验收。

## 5. 浏览器人工检查（当前环境待执行）

1. `npm install`、`npm run dev`，打开 Vite 本地地址；首次加载无黑面、无 Three.js Console 异常。
2. 工件装夹视角：炮塔安装孔从上方确实透空；侧装孔与轮孔均为实体视觉开孔。
3. “镗孔中心线”视角：找正时共轴误差逐渐归零；镗杆实体中心、青色示意轴线、孔圆心应重合。
4. 进入孔系加工阶段：A/B 两个孔各自进给与退刀，示意刀具不得穿过侧壁；工件和夹具保持固定。
5. DNC 阶段：工作间与 CNC 的**局部有线**传输光点可见，业务板只展示模拟发布包。
6. MDC 阶段：状态随时间轴变化；不得显示来自真实设备的假标识。
7. 检测阶段：每侧两个截面的演示采样点按顺序点亮；确认页面明确标注非实测。
8. 点击导出 JSON，检查文件中 `simulated:true`、`measured:false`，不得出现通过验收、真实 SHA 或机床远程启动。
9. 检查暂停、拖动、倍速、镜头导览、鼠标旋转和 ESC 详情功能。
