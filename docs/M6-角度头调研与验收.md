# M6｜大型落地镗铣床 90°角度头与车体放大设计、验收说明

**版本**：M6 / 2026-10-15  
**性质**：工业软件方案演示、未对接实机、非正式 NC/运动仿真/测量。

## 1. 研究结论与参考资料

固定直角铣头可将输入主轴运动转向 90° 输出。真实附件包括锥柄/法兰/联轴器、齿轮或其他转向机构、独立输出轴承、止转与定位机构，必须验证输入安装接口和输出工具空间包络；不能简单地旋转刀具网格以冒充已安装附件。

- **RETOS / SEMPUCO KFU-D2/90**：卧式镗铣床的自动定位附件实例，描述 headstock 安装以及铣削/镗削应用。<https://www.retos.cz/kfu-en>
- **Gerardi Evolution 角度头**：描述手动换装(MTC)、自动换装(ATC)、止转销、stop block、防转定位、通用法兰等附件功能。<https://www.gerardiusa.com/products/tooling/angle-heads/evolution>
- **YCM 高刚性90°头**：立/卧工况切换，涉及齿轮箱、联轴器、锁固和更换安全机构。<https://www.ycmcnc.com/en/product/1532483518786/1533199313959/1533549813930>
- **US5242358A**：卧式镗床自动角度头夹持与机外托架的工程示例；说明附件安装基准和锁固的重要性。<https://patents.google.com/patent/US5242358A/en>

**选型范围判断**：客户实际主轴锥孔、驱动联接、止转方式、头部质量、最大允许扭矩/转速、角度头外轮廓、额定轴向/径向力、自动/手动装夹和机床行程均待现场调查。本交付**不指定厂家实机型号**，不将网页产品参数直接写成客户机床参数。

## 2. 本演示的执行链路

1. 直镗杆完成 A/B 孔粗镗和精镗模拟，旋转停止后滑枕 Z 退回到安全位置；移动至示意附件更换位。
2. 主轴箱升高，旧镗杆组件移除；进入短暂无刀状态，安装固定式 90°角度头并显示止转销/止转块。**这是人工更换过程的状态动画，不表示存在自动换头机。**
3. 角度头固定壳体不旋转；输入 +Z，输出 −Y。先进行 X 横移，再沿 Z 前移到顶板目标点上方；随后通过 Y 下降执行**留净距的顶部加工动作**。
4. 输出刀具只在模拟进给阶段旋转。退刀时优先向上抬离顶部；此后完全退出 Z，再进入下一换装和检测状态。
5. 角度头退出后切换测头，原 M5 的虚拟测点规划与 JSON 摘要继续使用，**没有实际探测、切削、NC 发布或补偿写回**。

## 3. 坐标系与技术约束

世界坐标：右手系，Y 竖直。主轴输入方向 +Z；角度头输出 −Y。

关键定义：

- 车体等比放大：`HULL_SCALE={x:1.10,y:1.10,z:1.10}`，工作台维持原尺度。
- 机床场景原点移至 `Z=-6.65 m`，确保放大后直镗杆精镗进给与侧壁之间保留大于 0.09 m 的净距。
- 角度头输入端面沿用主轴 gauge plane 的 rigid-body 父子关系，新增独立输出 TCP：`worldX = machineX`、`worldZ = machineRootZ + ramExtension + 5.00`、`worldY = headY + spindleLocalY − 1.25`。
- 顶板表面选点在 `localX=1.60`、`localZ=−1.50`。顶板原始底面 `deckY−0.05`，厚 `0.09`，表面高度 `deckY+0.04`，按 1.10 缩放后计算 TCP 净距。
- `angleHeadDiagnostics` 中中心偏差量使用 (X,Z) 二维距离；**角度头靠近/撤离的运动坐标为 Y**，与直镗杆的 X/Y 对心、Z 进给明确不同。
- 净距 0.09 m 是示意动画安全边界，**不等于任何真实刀具允许悬空加工间隙或推荐刀补值**。画面不做实际材料去除。

## 4. 需要人工查验的项目

- [ ] Windows 本地 `npm install && npm test && npm run build` PASS，浏览器无模块/材质/WebGL 报错。
- [ ] 1080p 整体车间清晰显示；车体比 M5 大约 10%，压板无明显穿模，炮塔顶部仍然完全敞开。
- [ ] 两个直镗孔与镗杆视觉共轴；四道子工序按 A 粗/精 → B 粗/精播放。
- [ ] “换头”阶段主轴先停止、滑枕回位，再出现角度头；壳体静止，工具沿 −Y 输出方向旋转。
- [ ] 角度头从顶板外缘上方接近，刀具中心落在目标标记 X/Z 中心处；不能误入圆形炮塔开口；刀头在所有阶段不穿过顶板。
- [ ] “检测”阶段先完全退出角度头，再更换测头；过程数据小面板中含附件模式与 TCP、并明确模拟属性。
- [ ] 机床本地 DNC/MDC 不生成真实 CNC 启动命令，研发与生产安全域无跨域网络连接动画。
