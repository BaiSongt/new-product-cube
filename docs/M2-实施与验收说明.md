## 1. 本次实装范围

1. **车体几何**：前部多折面、左右车体侧板、后部倾斜板、底板、内部较低的可视内底板。侧面五组成对轮轴孔、两组侧安装孔为 `Shape.holes` + `ExtrudeGeometry` 的实际网格孔洞。顶部甲板采用圆形真实开口，开口周边设内缘及金属唇边。**没有炮塔、火炮、履带、车轮或完整内构件**。
2. **装夹**：八组示意支撑/压板；时间轴先完成夹具接触，再执行任何主轴动作。
3. **机床运动**：沿现有 X/Y/Z 层级复用 M1.2 运动结构，计入局部刀尖 X 偏置，依次定位安装孔 A 和 B，完成两轮进给、退刀。终点保留刀尖到车体侧壁的示意安全距离，不演示真实去料。
4. **程序链**：研发端到生产侧为人工介质移交；机旁工作间通过已画出的本地线缆与机床连接。DNC 阶段以移动光点表现**本地受控下发**，没有实际 CNC 连接。
5. **在线检测**：轴孔设计共轴线与圆环在检测阶段高亮；未伪造测点数值、不声称达到设计公差。
6. **界面**：保留单屏唯一 Three.js Canvas、点击选中、五个视角、信息标签、线框切换；新增六阶段直达、故事说明卡、自动镜头导览（用户手动旋转即关闭）与 78 秒回放。

## 4. 用户端的必要验收

先运行 `npm install && npm run dev`。依次执行：

1. 全景：机床与工件都显示，工件应是银灰色，不出现之前的整体黑色。
2. 工件装夹：旋转到正上方，确认炮塔安装位**中央透空**、可看到凹下的内部底板，不被盖板盖住。
3. 两侧轮孔：确认每一侧 5 处轮孔和 2 处侧面安装孔是穿孔，不是黑圆片；结构线开关不会偏移。
4. 播放/拖进度：先夹紧，再做 X/Y 定位，主轴对准两处上部安装孔，伸刀在工件侧壁前停住，不穿透车体。
5. 切换到 DNC：出现机旁工作间—机床的局部数据流示意，无外网线路。
6. 检测阶段：两侧设计轴孔高亮，页面没有出现未经验证的同轴度数值。
7. 按下暂停、复位、倍速、六阶段按钮与镜头按钮，均能正确操作；按 ESC 关闭详情。
8. 检查浏览器 Console，确认无 Three.js/WebGL 错误与加载异常。
