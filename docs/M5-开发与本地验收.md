# M5：镗铣床机械装配、工序和几何诊断

版本：M5 / 2026-10-15  
基线：M4；M5 是独立工程目录，不覆盖 M4。

## 1. 建设范围

本轮继续一台落地镗铣床、战车车体、独立离线工作间的三维建设方案演示。保留研发与生产物理隔离、受控介质人工交接、DNC 本地下发、MDC 只读监测、过程检测规划和质量追溯。

新增：

1. 主轴机械链：机床安装节点 → X 立柱 → Y 主轴箱 → Z 滑枕 → 主轴接口基准端面 → 法兰 → 刀柄 → 镗杆前端；测头与镗杆互斥可见。
2. 主轴旋转绕镗杆中心线。刀片可以径向布置，但从不以其外缘代替孔中心线。停止旋转时保留角度，避免转位画面跳变。
3. 两处安装孔分别展开粗镗和精镗说明，共四道确定性子工序。粗镗、精镗仅以两档示意进给范围区分；两档均止于工件侧壁之外，不进行真实材料去除。
4. 当前工序卡（左下中部）：当前孔、工序名、运动阶段、轴向最近表面净距、刀轴至目标孔中心线距离、四工序跳转。
5. 小型 JSON 数据面板继续采用 M4 的紧凑抽屉，并同步输出 `operation`、`toolAssembly`、`spindleReference` 和几何诊断；标注全部为模拟。
6. 虚拟测头球面前缘纳入安全净距计算；多截面采点是可视化规划，不能作为实测值。

## 2. 坐标系与参考点

- 三维世界：右手系，Y 向上，单位米。
- 演示机床根坐标的世界 Z 偏置为 `machineRootZ = -6.4`。
- X 为立柱横移、Y 为主轴箱升降、Z 为滑枕向工件进退。`spindleLocalY = 0.02` 是演示机械安装偏置，旋转轴父节点自身移动该偏置，子镗杆仍相对旋转轴放置在 `(0,0,z)`，杜绝旋转偏心。
- 端面 `gaugePlaneLocalZ = 4.14`；镗杆/测头参考中心位于 `6.18`。这些数字只用于场景；不得当作实机主轴和刀具的几何尺寸。
- 正向运动学：`worldX = carriageX + spindleLocalX`，`worldY = headstockY + spindleLocalY`，`worldZ = machineRootZ + ramExtension + localZ`。
- 主轴对孔偏差计算 `sqrt((worldX-holeX)^2+(worldY-holeY)^2)`，不把 Z 向进给行程纳入横向同轴偏差。
- 安全净距是最靠近外侧壁的刀具/测头表面到外侧壁的 Z 距离。测头按球心前缘加半径计算。

## 3. 四工序时间轴

总长 **108 秒**，沿用七大业务阶段：研发、装夹、找正、DNC、镗孔、检测、追溯。

| 子工序 | 进度区间 | 动作 | Z 伸出峰值（示意） |
| --- | --- | --- | ---: |
| A-ROUGH | 0.39–0.46 | 粗镗进给→退刀 | 0.70 m |
| A-FINISH | 0.46–0.57 | 精镗进给→退刀 | 0.87 m |
| B-ROUGH | 0.67–0.73 | 粗镗进给→退刀 | 0.70 m |
| B-FINISH | 0.73–0.83 | 精镗进给→退刀 | 0.87 m |

两孔之间横移只在 Z 已退至 `0.06 m` 的状态进行，归档时测头先退回再移走。

## 4. 本地操作

从项目根目录启动：

```powershell
npm install
npm test
npm run build
npm run dev
```

Windows 可双击 `start-windows.bat`。在网页中选择“镗孔中心线”视角，点击下方的“加工”阶段，依次观察：

1. 当前工序从 A-ROUGH → A-FINISH → B-ROUGH → B-FINISH 变化。
2. 刀具装配绕镗杆中心线旋转，没有公转摆动；主轴、镗杆与孔中心线共线。
3. 每次粗/精镗完成后 Z 退至初始位置；B 孔定位前不得发生未退刀横移。
4. 当前工序卡里的轴线误差在稳定加工段应显示 `0.0 mm（场景计算）`，进给时安全净距保持正值。
5. 检测阶段测头替换镗杆，采样规划点逐渐显示；球体前表面不与近侧壁相交。
6. DNC 工作间只在本地链路播放数据光点，不出现研发网与生产网的数据直连。
7. 小型“过程数据”面板默认收起，展开后可查看工序与机床参考点完整模拟 JSON。

## 5. 自动化验收及限制

- `npm test` 验证时间轴阶段边界连续性、共轴误差、四工序完整性、工件安全净距、原有隔离流程和数据面板。
- 新增专项测试对 6001 个动画时刻验证理论正向运动学与安全净距，并用 10001 个时刻验证机床横移先退刀的顺序。
- 自动化测试并不等同于浏览器视觉验收、实机运动学验证、工件碰撞认证、测头标定或 NC 实际运行。
- 真实机床往往可能存在独立 W 镗轴、附件铣头、回转台与不同的刀柄主轴接口；M5 不凭空声明真实资源信息。
- 工件是 Three.js 可视网格，不是可用于 CAM 求解的 B-Rep STEP；真实孔数、间距、同轴度、测量点位必须按客户图纸与计量方案确定。

## 6. M6 建议

1. 客户提供实机铭牌、CNC 版本、机床 X/Y/Z/W 轴运动和工作台/附件配置后，引入可替换的运动学模型文件。
2. 实际测绘的刀柄安装面、刀具组件、镗杆伸出、刀具长度补偿以及可换式测头型号。
3. 真实车体 STEP / 夹具模型、规范的装夹姿态、CAM 工序刀路与机床行程、干涉验证。
4. 机床视频/状态采集和 DNC/MDC 演示回放数据的离线样本替换，明确样本时间戳与出处。
5. 两侧孔独立测量方案、计量不确定度与孔轴线拟合报告视图，直至客户签署的工程验收方案。
